## 📖 About

🔹 **Terraria — Fargo's Mutant Mod** is a powerful tool built to help you simplify item acquisition in Terraria with the Mutant NPC who sells boss summons and event items. The Mutant NPC provides a convenient shop for summoning items, making boss grinding and event triggering effortless.

🔸 Whether you're a seasoned professional or just getting started, **Terraria — Fargo's Mutant Mod** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their Terraria modding workflow. Download now and get started in minutes. 🚀

## 🚀 Features

| Feature | Description |
|---------|-------------|
| Mutant NPC | New town NPC that sells boss summon items and event triggers |
| Boss Summons | Purchase any boss summon item directly without grinding drops |
| Event Control | Buy event-triggering items like Goblin Battle Standards and Pirate Maps |
| Fargo's Soul Companion | Works best alongside Fargo's Souls Mod for the full experience |
